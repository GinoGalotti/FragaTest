## Weekly numbers for leadership

Ask yourself: which 5–7 numbers? Mix outcomes with signals that warn early, each with a target and a trend.

| Number | Target | Why leadership cares |
|---|---|---|
| | | |

Candidates: golden-set pass rate (per criterion) · safety violations (privacy, repealed citations) · thumbs-down rate and rating coverage · p95 latency at peak · availability vs 99.5 % · flaky-test rate and pipeline time · escaped defects / incidents and time to detect · releases shipped vs planned.

## Release scenario (live): how I reason

- Which gate is failing? Is it a risk to users or to our process?
- Blast radius: one app or all five? Can it be rolled back? Is a feature flag available?
- Options: ship, ship with mitigation, delay. Make the recommendation, then name the risk that remains and who accepts it.
